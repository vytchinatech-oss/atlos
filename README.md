# Атлос — веб-приложение (быстрый вариант)

Журнал тренировок, который ставится на экран телефона (PWA). Работает без интернета. Данные хранятся в телефоне,
а резервная копия выгружается в файл (раздел «Данные»).

## Состав

| Файл | Что это |
| --- | --- |
| `index.html` | Всё приложение: интерфейс, библиотека упражнений, анимации, таймеры, статистика |
| `sw.js` | Фоновый модуль: офлайн-режим и тихие обновления |
| `manifest.webmanifest` | Название, иконка, режим «на весь экран» |
| `icons/`, `fonts/` | Иконки и шрифт Onest (локально, без внешних запросов) |
| `build.py` | Ставит номер версии перед выкладкой |

## Выпуск обновления

```bash
python3 build.py          # новая версия в index.html и sw.js
git add -A && git commit -m "Описание изменений" && git push
```

GitHub Pages выкладывает новую версию за 1–2 минуты. Телефоны скачают её в фоне при следующем
открытии и покажут «Доступна новая версия → Обновить». Данные и начатая тренировка при этом сохраняются.

## Важно про данные

Данные привязаны к адресу сайта. Если сменить домен, тренировки на новом адресе
переносятся через «Сохранить копию» → «Восстановить из файла».

## Проверка локально

```bash
python3 -m http.server 8000   # открыть http://localhost:8000
```
